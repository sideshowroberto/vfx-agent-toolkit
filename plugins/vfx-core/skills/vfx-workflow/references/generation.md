# Image and video generation

Provenance: audited 2026-09 in the vfx-agent-toolkit-codex repository; its docs/,
codex/tests/ and codex/recipes/ hold the evidence records and probes named below.

Preserve the useful directing brief: subject identity, reference roles, action,
camera endpoints, lighting, continuity and the requested output. Use the user's
existing brief; intake length and one-beat/one-move recipes are optional defaults.
Prompted logo/identity preservation is not a pixel-accuracy guarantee.

Discover the selected provider's current schema before submitting. Reference
roles, duration, resolution, prompt limits, model IDs and costs vary by provider
and account. Keep account folder IDs and preferences outside shared guidance.
The Seedance reference corpus ships with the seedance-vfx plugin (seedance-20/references).

Track upload/finalize/generation states and partial batch failures. Inspect media
bytes, channels and colorspace; an RGB JPEG fallback discards alpha and adds loss.
Use reference roles for their creative purpose, not to bypass a service refusal.

Evidence: G1-G3. No provider schema or
paid generation was verified in this pass. Prompt-quality experiments remain
separate from factual API compatibility checks.
