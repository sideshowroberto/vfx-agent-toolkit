--------------------------------------------------------------------------------
WHAT IT CHECKS (6 VALIDATIONS)
--------------------------------------------------------------------------------

1. Filename Format
   ✅ PASS: documentation-specialist.md
   ❌ FAIL: documentation-specialist-v2.md (version suffix)
   ❌ FAIL: DocumentationSpecialist.md (CamelCase)
   ❌ FAIL: documentation_specialist.md (snake_case)

2. Metadata Present
   Required fields in YAML frontmatter:
   - name: agent-name
   - description: What + When + Triggers
   - version: X.Y.Z
   - last_updated: YYYY-MM-DD
   - status: active | deprecated | experimental

3. Name Matches Filename
   File: documentation-specialist.md
   Metadata: name: documentation-specialist
   ✅ Must match exactly

4. Version Format
   ✅ PASS: 1.0.0, 2.1.3, 10.20.30
   ❌ FAIL: v1.0.0, 1.0, 1.0.0-beta, 1.0.0.0

5. Changelog Exists
   - Version 1.0.0: Optional
   - Version > 1.0.0: Required "## Version History" section
   - Must document at least 2 versions (current + previous)

6. Description Quality
   - Length: 10-300 characters
   - No vague language: "helps with", "does stuff", "manages things"
   - Must have triggers: "use when", "for", "when"
   - Formula: What + When + Triggers
